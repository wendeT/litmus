LITMUS: Language Integrity Test via Minimal Utility Scale

A large-scale language integrity benchmark, testing whether Large language models can read and write the world's languages correctly.

In the LITMUS project, we systematically evaluate whether large language models (LLMs) can read, process, and produce text across large sets of the world languages. We create an automatic evaluation across roughly 1,850 languages, to test wheather LLMs have basic language processing competence.

Motivation

Most languages a model was trained on have never been tested

Large language models are already used to answer health questions, explain government forms, and support education, in hundreds of languages.

    • For most of these languages, we have little evidence that a model works. Standard benchmarks require labeled data that the majority of the world's languages lack (Joshi et al., 2020).
    • General-purpose benchmarks reach around 200 languages (NLLB Team, 2022), yet usable text exists for well over a thousand (Kargaran et al., 2023). The gap between the two stays largely untested.
    • A model can fail silently in a language for years. The failure surfaces only when a speaker encounters it, not through any systematic check.

Method

Three tiers, each testing a deeper layer of language ability

We organized the project as a sequence of automatically scored probes, grouped into three tiers. We can run each tier without human-annotated answers, which lets us apply the same method uniformly across languages.

01Surface

Surface probes

Can the model correctly handle the building blocks of a language: characters, words, and simple, exact manipulations of them, such as spelling a word out or swapping two letters? This is the tier covered by the current experiment.

In progress
02Drift

Language drift probe

When asked to write in a given language, does the model's output stay in that language, or does it drift into English or a related language partway through the response?

03Meaning

Translation consistency probe

Current experiment

Tier 1: thirteen surface tasks, plus a control

We selected each task using three criteria: it can be scored automatically without a human judge, it tests something behaviorally distinct from the other tasks, and it is simple enough to explain in one sentence.

Automatic Distinct Explainable
Copy-back (control)
Repeat a piece of text back unchanged. Establishes a baseline.
in → out, unchanged
Spelling
Given a word, output it with a space between every character.
cat → c a t
Inverse spelling
Given characters separated by spaces, write the word they form.
c a t → cat
Contains character
Does a word contain a specified character? Answer yes or no.
cat, "a" → yes
Contains word
Does a sentence contain a specified word? Answer yes or no.
[the cat sat], "cat" → yes
Orthographic similarity
Given a target word and two candidates, choose the one closer in spelling to the target.
cat: bat / frog → bat
Character insertion
Insert a specified character after every occurrence of another character in a word.
cat, insert x after a → caxt
Word insertion
Insert a specified word after every occurrence of another word in a sentence.
[the cat sat], insert big after the → the big cat sat
Character deletion
Delete every occurrence of a specified character from a word.
balloon, delete l → baoon
Word deletion
Delete every occurrence of a specified word from a sentence.
[the dog chased the cat], delete the → dog chased cat
Character substitution
Replace every occurrence of a character with another character in a word.
cat, a → o → cot
Word substitution
Replace every occurrence of a word with another word in a sentence.
[the cat sat], the → a → a cat sat
Character swapping
Swap two specified characters at given positions in a word.
cat, positions 1 & 3 → tac
Word swapping
Swap two specified words at given positions in a sentence.
[the cat sat on the mat], positions 2 & 4 → the on sat cat the mat

Literature

Our task selection is based on prior work

Our benchmark combines tasks from CUTE and EXECUTE (Edman, Schmid & Fraser, 2024, 2025), which test how well a model understands its own tokenizer; LMentry (Efrat, Honovich & Levy, 2023), a benchmark of elementary language tasks; PhonologyBench (Suvarna, Khandelwal & Peng, 2024); StringBench (Wang, Fu, Wang & Gong, 2025) and CharBench (Uzan & Pinter, 2025), on string and character-level processing; a study by Shin & Kaneko (2024) on word composition; TASE (Zhao, Wang, Huang, Lu & Liu, 2024); and SubTokenTest (Hou, Hu & Zhang, 2026). From this body of work, we selected tasks that are automatic, distinct, and easy to explain. Tasks with these properties can be scored without a human judge, which is what makes it possible to cover a large number of languages, since most languages have no annotated data to build a standard benchmark from.

Findings so far

Initial pilot results and analysis

  • We observe a noticeable variation in accuracy across the thirteen tasks and across languages.
  • Part of that variation is related to how well a language's writing system is represented in the model. Languages that are handled less efficiently at the character level tend to score lower.
  • Some tasks are difficult even for English, which is the most represented in most LLM trainings. That points to part of the difficulty coming from the model's underlying architecture, not only from how much training data exists for a language.
  • We keep the full breakdown, by task, by language, and by model, on the interactive results dashboard rather than reproducing it here.

Roadmap

What is running now, and what comes next

  • We are running Tier 1 (surface probes) now, across roughly 1,850 languages and two models.
  • We plan Tier 2 (language drift probe) and Tier 3 (translation consistency probe) next, extending the same automatic-scoring approach to deeper aspects of language ability.
  • We plan an instruction-following probe using human-annotated prompts written in the target language, to evaluate post-training alignment across languages rather than only base language handling.
